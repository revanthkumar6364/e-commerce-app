# E-Commerce Application

A premium, full-stack E-Commerce application built with modern web technologies.

## Project Structure

The project is divided into two main components:

- **Frontend**: A dynamic, responsive user interface built with Vite and React.
- **Backend**: A robust Node.js and Express API for managing authentication, users, and data.

## Features

### Frontend
- **Premium UI/UX**: Modern design with smooth animations and responsive layouts.
- **Dynamic Product Browsing**: Seamlessly browse through various product categories.
- **Dedicated Pages**: Including Travel destinations, Products, FAQ, Terms & Conditions, and Cancellations.
- **Global Search & Navigation**: Integrated MegaMenu and easy-to-use search.

### Backend
- **Authentication**: Secure user login and registration flows.
- **User Management**: API endpoints for handling user profiles and data.
- **Scalable Architecture**: Organized routes and controllers for easy extension.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/revanthkumar6364/e-commerce-app.git
   cd e-commerce-app
   ```

2. **Setup Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Setup Backend**:
   ```bash
   cd ../my-backend
   npm install
   npm start
   ```

## Technologies Used

- **Frontend**: React, Vite, Vanilla CSS
- **Backend**: Node.js, Express, MongoDB (if applicable, please update), JWT
- **Version Control**: Git & GitHub
